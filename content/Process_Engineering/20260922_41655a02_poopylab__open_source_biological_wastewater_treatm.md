This software is highly useful for process engineers and environmental scientists involved in the design, analysis, and optimization of wastewater treatment plants. ## 📖 Content
PooPyLab is an open-source software designed for the simulation of biological wastewater treatment processes. It allows users to construct process flow diagrams (PFDs) for treatment plants and obtain steady-state results.

**Installation:**
The PooPyLab package can be installed using pip:
```bash
pip3 install poopylab
```

**Usage and Documentation:**
*   **Examples:** The `examples/` folder within the repository provides demonstrations on how to utilize the available classes and methods to build custom treatment plant PFDs and perform simulations.
*   **Detailed Documentation:** Further documentation is available at [toogad.github.io/brownbook](https://toogad.github.io/brownbook/index.html).
*   **Wiki/Tutorial:** A project wiki, intended for more detailed information and tutorials, can be found at [PooPyLab Wiki](https://github.com/toogad/PooPyLab_Project/wiki).
