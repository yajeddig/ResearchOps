## 🎯 Relevance
This group provides valuable open-source tools and methodologies for process engineers and industrial data scientists focused on sustainability. It offers practical applications of Life Cycle Assessment (LCA) and Techno-Economic Analysis (TEA) for designing and evaluating industrial processes, particularly in water treatment, sanitation, and resource recovery, contributing to more sustainable industrial practices and decision-making.

## 📖 Content
The Quantitative Sustainable Design (QSD) Group is a GitHub organization dedicated to developing tools for quantitative sustainable design (QSD). These tools aim to guide the research, development, and deployment of technologies and inform decision-making, particularly in the context of sustainability.

The organization's primary focus, as evidenced by its pinned repositories and most used topics, is on sanitation and resource recovery systems. Key methodologies employed and supported by their tools include Life Cycle Assessment (LCA) and Techno-Economic Analysis (TEA).

**Key Repositories:**

*   **QSDsan**: Public repository for "Quantitative Sustainable Design (QSD) of sanitation and resource recovery systems." Developed in Python, it has 45 stargazers and 30 forks, last updated Sep 16, 2026.
*   **EXPOsan**: Public repository for "EXPOsition of sanitation and resource recovery systems." Also in Python, with 23 stargazers and 19 forks, last updated Sep 15, 2026.
*   **QSDsan-env**: Environment repository for launching QSDsan-related packages in Binder, using Dockerfile.
*   **nj-bioenergy-app** (forked from NMS26/QSDsan-frontend): Frontend of the NJ bioenergy app, developed in JavaScript.
*   **nj-bioenergy-api**: Backend of the NJ bioenergy app, developed in Python.
*   **WSP_solar_inactivation**: Public archive, Python-based.
*   **QSDsan-webapp** and **QSDsan-webapp-backend-api**: Archived web application components for QSDsan, using JavaScript and Python respectively.
*   **QSDsan-website**: Archived website for QSDsan, using SCSS.
